首个可从 GitHub Releases 直接下载的个人正式安装包。

- 每天 2 次预设 08:00、18:00，每天 3 次预设 08:00、12:00、18:00；均可修改，保存前须人工核对。
- 草稿同步、服药记录、本地提醒与自适应图标延续 0.2.2 的功能。
- 正式版关闭调试功能，使用固定发行签名；Android 9 及以上通过签名迁移链兼容此前在本机安装的调试版，无需卸载。Android 8 使用原签名保持兼容。
- 后续开发版单独显示为 Mediary Dev，使用独立数据，不覆盖日常使用的 Mediary。

下载安装：点击下方 Assets 中的 **mediary.apk**。手机提示时允许当前浏览器或文件管理器安装应用，之后可关闭这项安装权限。更新时选择覆盖安装，不要先卸载；卸载会清除手机本地数据。

下载校验：SHA256SUMS 提供 APK 的 SHA-256；release-info.json 提供版本、源码提交及公开签名指纹。它们均不包含服务口令、模型密钥或医嘱。

本地提醒在确认后不依赖网络；ChatGPT 草稿同步仍需自行配置个人服务。安装包不附带任何人的服务口令。

当前仍属个人自用早期版本。短时真机测试不能保证所有后台、锁屏、断网、重启场景必达；此前报告的闪退尚未捕获应用异常堆栈，不宣称已彻底解决。
